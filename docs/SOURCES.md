## Original art and media use

The orbital mark, rover panorama, destination map and hardware plates are AI-assisted project illustrations. They are scenic interpretations. NASA archival image permissions and limitations are described in the [NASA media guidelines](https://www.nasa.gov/nasa-brand-center/images-and-media/).
