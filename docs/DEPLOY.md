# Publish the museum with GitHub Pages

1. Unzip the project. Open the folder containing **index.html**.
2. Sign in to GitHub. Use **New repository**, choose a name such as **space-ghosts**, set visibility to **Public** for GitHub Free, and create the repository.
3. On the empty repository page, choose **uploading an existing file**. If the repository already has a README, use **Add file → Upload files**.
4. Drag the contents of the unzipped project folder into the upload area, keeping folders together. Commit the files to the default branch. You should see **index.html** on the repository's first page. If it sits inside another folder, move its contents up one level.
5. Open the repository's **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**. Select the branch containing your files (usually **main**) and **/(root)**, then save.
6. Allow up to ten minutes. Return to **Settings → Pages** and open **Visit site**. Copy that address. For a project repository, it generally looks like https://YOUR-USERNAME.github.io/space-ghosts/.
7. Open the address in a private browser window. Open a mission file and try a quiz question. For later updates, replace the changed files in the same branch.
